# Зошит — бібліотека знань

Статичний навчальний сайт українською мовою: предмети → теми → параграфи. Додавай описи й зображення, шукай матеріали, редагуй і видаляй записи.

Щоб опублікувати сайт і отримати посилання для друзів, двічі клацни `Опублікувати_сайт.bat`. Під час першого запуску файл:

1. Запропонує встановити офіційний GitHub CLI, якщо його ще немає.
2. Відкриє GitHub для входу в обліковий запис.
3. Створить відкритий репозиторій і ввімкне автоматичну публікацію GitHub Pages.
4. Дочекається завершення публікації та відкриє сайт.

Потрібні Git for Windows та Windows Package Manager (`winget`), щоб автоматично встановити GitHub CLI. Якщо відкрита назва репозиторію зайнята, файл попросить ввести іншу.

Матеріали зберігаються локально у браузері на цьому пристрої. Вони не потрапляють у GitHub і не синхронізуються між пристроями. Щоб перенести їх до іншого браузера, скористайся кнопками експорту й імпорту копії.
