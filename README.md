# Зошит — бібліотека знань

Статичний навчальний сайт українською мовою: предмети → теми → параграфи. Додавай описи й зображення, шукай матеріали, редагуй і видаляй записи.

Відкрий `index.html` у браузері або опублікуй файли репозиторію через GitHub Pages.

Матеріали зберігаються локально у браузері на цьому пристрої. Щоб перенести їх до іншого браузера, скористайся кнопками експорту й імпорту копії. Сайт не надсилає дані на сервер.
