# Зошит — бібліотека знань

Статичний навчальний сайт українською мовою: предмети → теми → параграфи. Додавай описи й зображення, шукай матеріали, редагуй і видаляй записи.

Щоб опублікувати сайт і отримати посилання для друзів, двічі клацни `Опублікувати_сайт.bat`. Під час першого запуску файл:

1. Запропонує встановити офіційний GitHub CLI, якщо його ще немає.
2. Відкриє GitHub для входу в обліковий запис.
3. Створить відкритий репозиторій і ввімкне автоматичну публікацію GitHub Pages.
4. Дочекається завершення публікації та відкриє сайт.

Потрібні Git for Windows та Windows Package Manager (`winget`), щоб автоматично встановити GitHub CLI. Якщо відкрита назва репозиторію зайнята, файл попросить ввести іншу.

## Спільна бібліотека та адміністратор

Сайт розміщується на GitHub Pages, тому сам GitHub не може безпечно приймати зміни від браузерів. Для спільного каталогу використовується Supabase: відвідувачі читають матеріали без входу, а змінювати їх може лише адміністратор. Перевірка прав виконується в базі даних, а не лише кнопками інтерфейсу.

Щоб увімкнути спільну бібліотеку:

1. Створи проєкт Supabase і відкрий у ньому **SQL Editor**.
2. Встав і виконай увесь файл `supabase/schema.sql`.
3. У **Project Settings → API Keys** скопіюй Project URL і **publishable key**. Додай їх у `supabase-config.js`. Не вставляй `secret` або `service_role` key у сайт.
4. У **Authentication → URL Configuration** додай адресу `https://uyli228.github.io/zoshyt-school-notes/` до дозволених redirect URLs.
5. Опублікуй оновлений сайт файлом `Опублікувати_сайт.bat`.
6. На сайті натисни **Вхід адміністратора**, введи свою пошту та відкрий посилання з листа.
7. У Supabase **Authentication → Users** скопіюй UUID свого користувача. У **SQL Editor** виконай запит із кінця `supabase/schema.sql`, підставивши цей UUID замість прикладу.
8. Онови сайт. Якщо в цьому браузері є стара локальна бібліотека, натисни **Перенести їх у спільну бібліотеку**.

Після цього всі відвідувачі бачитимуть однакові предмети, теми й параграфи. Зміни адміністратора з’являтимуться на відкритих сторінках через спільні оновлення. Інші користувачі не отримують права запису, навіть якщо спробують викликати API напряму.

До підключення Supabase сайт залишиться в локальному режимі, а помітка на сторінці попереджатиме, що зміни видно лише в цьому браузері. Експорт копії доступний усім; імпорт — адміністратору.
